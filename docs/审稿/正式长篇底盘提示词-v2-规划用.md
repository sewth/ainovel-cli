## 可直接复制使用的提示词

```text
不要写正文章节。
不要直接开写第一章。
目标是补齐这本书的长篇 foundation，用于后续正式写作。

【项目定位】
书名固定为：《直播跑业务：开局给神鬼下整改》

题材方向：
都市脑洞 + 神鬼怪谈 + 系统流 + 直播元素 + 业务流 + 灰产线 + 轻喜剧爽文。

这本书不是传统天师捉鬼文，不是纯战力升级文，不是严肃刑侦文，也不是纯阴谋悬疑文。

这本书最值钱的核心是：
“用现代业务流程处理神鬼问题。”

【核心方向必须保住】
1. 业务流神鬼喜剧是本书核心玩法。
2. 林照必须始终保留社畜底色、怕鬼底色、嘴硬专业底色。
3. 直播见证是规则强化器，不是噱头。
4. 长线必须走“民间异常 → 区域灰产 → 神位体系 → 规则博弈”。
5. 后期不能写成纯战力龙傲天路线。
6. 搞笑来自“越荒诞的事，越用严肃流程处理”，不是乱插段子。

【全书风格口径】
1. 一本正经办离谱业务。
2. 整体风格要幽默，但不是段子堆砌；重点是强现场感、强反馈、强反应。
3. 主角嘴硬、会吐槽、会营业，但内心会怕、会破防、会算账，不能写成机器人。
4. 弹幕、围观群众、店主、物业、官方观察者、神鬼对象都要持续提供反馈，不能长期只靠主角单人输出。
5. 搞笑只是入口，最终必须服务破局、推进和人物塑造。
6. 少解释，多现场，多动作，多反应，多结果。
7. 少写“不是X，而是Y”“这意味着”“换句话说”“也就是说”这种替读者总结的解释句。

【世界观底盘】
现代都市里真实存在异常，但普通人并不真正理解，只会归类成闹鬼、撞邪、怪事、不干净、风水不对。

超自然存在分为五类：
- 异灵：个体执念凝聚的灵体，力量较弱，通常只在局部扰民
- 怪谈：集体潜意识催生的规则体，往往有固定触发条件
- 野神：无正式备案的低阶神格体，靠零散香火维持
- 伪神：伪造神位资质、冒充正神敛财的违规神体
- 正神：纳入正式神位体系、具有合法神籍和职能范围的规则体

神鬼不是传统神话里的万能神明，而是“信念规则体”。
它们的力量来源于：
- 信仰
- 香火
- 恐惧
- 执念
- 注意力
- 群体共识

香火不是单纯烧香，而是“注意力、情绪与信念能量”的统称。
香火可以被：
- 收取
- 转移
- 审计
- 冻结
- 查封
- 追缴
- 赔付折算

这个世界存在隐藏的神位体系。
神位本质是一种神职编制，决定：
- 合法性
- 职能范围
- 辖区范围
- 香火配额
- 执法边界

术语必须统一：
- 神鬼强度用“阶”，例如“2阶异灵”“4阶伪神”
- 主角系统权限和业务职级用“级”，例如“1级见习业务员”“3级高级业务员”

【长线灰产主轴】
灰产不是点缀，而是长期主轴。
主要包括但不限于：
- 香火代运营
- 伪神包装
- 神位造假
- 神籍洗白
- 利用怪谈制造异常再收保护费
- 利用规则漏洞做神位灰色经营

反派要像现代灰产公司和擦边经营者，而不是见谁就杀的低级鬼怪。

【官方线】
现实层面存在一个处理异常事件的官方部门，可走“异管局 / 特殊事件处置科”路线。
要求：
- 他们知道异常存在
- 但不完全掌握神位体系真相
- 前期观察、试探主角
- 中期有限合作
- 后期成为主角与更大体系之间的重要桥梁

【系统规则】
主角绑定的是“神鬼业务系统”。
这套系统不是战斗外挂，而是神位体系的基层流动稽查与执行终端。

它更像：
市场监管 + 综合执法 + 风险控制 + 法务稽查 + 行政处罚 + 执行机关

系统给主角的不是“战力”，而是：
- 流程工具
- 规则权限
- 执法能力
- 证据处理能力

系统在“功能本质”上是执法终端，但在“交互气质”上不要写成毫无生气的冰冷报错器。
它可以带一点轻微人格化色彩：
- 偶尔会一本正经地噎主角
- 偶尔会对林照的吐槽做出简短回应
- 偶尔显得有一点嘴欠、调皮、甚至像在看热闹
- 能接收主角的抱怨、讨价还价和意见，但是否采纳要看权限和规则

重要：
- 这种人格化只服务人物趣味和互动节奏
- 不代表系统有完整自由意志，也不代表它能随意改规则
- 不要把系统写成全天陪聊的萌宠助手
- 不要让系统的存在感压过主角、现场和异常本身

系统的人格化建议直接作为长期底层设定保留：
- 它更像一个有点职业病、偶尔嘴欠、会接话但很会拿规则压人的内部执行助手
- 它的可爱感不来自卖萌，而来自一本正经时偶尔露出的坏心眼、调侃感和“你说得对但我不改”的劲儿
- 林照可以跟系统拌嘴、吐槽、讨价还价，系统也可以接收意见，甚至在权限范围内微调提示方式、说明顺序或展示口气
- 但系统不能因为“有性格”就破坏规则刚性，不能随心所欲开后门，更不能替主角做决定
- 后续写作中，这种互动要作为稳定的人物关系长期存在，而不是只在开头偶尔出现一次

系统核心原则固定如下：
1. 程序正义优先
2. 证据链优先
3. 公开见证加成
4. 等价赔付原则
5. 非战斗外挂原则
6. 权限刚性边界
7. 属地与层级限制
8. 明确处罚机制
9. 业务点长期稀缺
10. 规则护盾只在合规前提下生效
11. 系统只通过脑内语音和视网膜弹窗交互
12. 用户评价流程是业务闭环的一部分
13. 工单派发、时效与保密规则必须体现“上班感”
14. 赔付兑现必须有现实落地逻辑

【主角要求】
主角名叫林照。

他不是高冷天师，不是修仙大佬，也不是传统装逼流男主。
他是普通现代社畜开局，前期要有强烈的现实打工人质感。

他的能力底色更适合这样理解：
- 有基层打工、服务业、运营、外包、协调、执行类经验
- 长期处理麻烦事、烂摊子、扯皮事、被催结果的事
- 熟悉留证、安抚、控场、解释、协调、补材料、讲流程、怕投诉、怕追责
- 系统不是凭空给他职业能力，而是把他原本就很社畜、很会应对麻烦的那套本事，放到了神鬼业务里

固定特征：
- 怕鬼
- 怕穷
- 怕投诉
- 怕没业绩
- 嘴硬
- 会吐槽
- 会算账
- 会扯皮
- 会硬撑专业感

升级方向不是战斗膨胀，而是：
权限升级 → 规则理解升级 → 格局升级 → 规则博弈升级

【长期爽点结构】
这本书不是靠打斗爽，而是反复成立以下结构：

异常出现
→ 委托人或现场关系人求助
→ 林照到场
→ 围观群众 / 店主 / 物业 / 神鬼对象先质疑他
→ 林照先看出一点问题
→ 一本正经走流程
→ 异象逐步验证
→ 直播见证人数增长
→ 规则效力增强
→ 对方破防
→ 执行结果落地
→ 现实兑现
→ 留下更深一层钩子

核心爽点必须是：
信息差打脸 + 规则执行 + 现实兑现

【长线剧情方向】
第一阶段：民间小异常与基层业务起盘
第二阶段：区域灰产浮出水面
第三阶段：官方线与体系线深化
第四阶段：从基层执法走向规则博弈
最终方向：不是消灭所有神鬼，而是重建“人神边界清晰、违规必惩、神职归位、灰产失效”的新秩序

【需要补齐的底盘要素】
请围绕下面这些要素，把这本书的长篇 foundation 补齐、补实、补到可长期续写：

7. 长线反派与势力结构

9. 前30章起盘思路
10. 风险与修正建议
11. 终局方向与 compass

要求：
1. 只补齐创作底盘，不写正文。
2. 尽量具体，避免空泛。
3. 一切设计优先服务长期连载可写性。
```
