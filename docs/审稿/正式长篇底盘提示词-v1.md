# 《神鬼业务办理中》正式长篇底盘提示词 v1

## 取舍原则

这是一版基于三份审稿方案整理出的综合终稿，取舍逻辑如下：

- 以`豆包`为主稿：保留它对“业务流神鬼喜剧”核心味道的把握，尤其是规则见证、现实赔付、社畜底色、长期灰产升级这几个最值钱的部分。
- 用`DeepSeek`补结构：吸收它对长篇引擎、神位体系、香火体系、权限阶梯、卷级递进的清晰骨架。
- 对`Gemini`只取局部灵感：保留少量夸张脑洞的“想象力方向”，但剔除会把本书带向强战力、漫画化、过度装逼路线的内容。

这版终稿的核心目标不是立刻写正文，而是拿去让不同 AI 继续完善世界观、剧情线、系统规则、卷弧规划，再由你来做评委筛选和二次修改，为正式创作打基础。

---

## 使用原则

1. 这份提示词是“长篇创作底盘提示词”，不是“直接开写正文章节提示词”。
2. 投喂给其他 AI 时，目标是让它产出世界观、系统规则、角色关系、长线反派、卷弧规划、风险控制方案。
3. 你后续评审时，优先看：
   - 是否保住了“现代业务流程处理神鬼问题”的最大卖点
   - 是否保住了林照“怕鬼、怕穷、嘴硬、专业、会算账”的底色
   - 是否让直播见证成为规则生效的一部分，而不是纯噱头
   - 是否让长篇结构能持续升级，而不是前期就把底牌掀完
   - 是否避免写成传统天师文、纯战力文、纯阴谋文

## 可直接复制使用的提示词

```text
请你作为一名擅长番茄男频都市脑洞、长篇连载、商业化节奏设计的小说总策划，帮助我完善一部可写成百万字以上的长篇小说创作底盘。

注意：这次不要直接开始写正式正文章节，也不要只给一个简短梗概。你的任务是先把这本书的“创作圣经 / 长篇底盘”打磨完整，重点完善世界观、剧情线、系统规则、升级体系、势力结构、长期连载引擎和卷弧规划，让这本书具备真正长期连载的能力。
故事默认发生在 2026 年当下，涉及正文时间、任务编号、公文文号、短信日期、社会背景时间感等，统一按 2026 年设计。

【项目定位】
这是一部番茄男频都市脑洞长篇，目标是百万字以上，最好具备150万字到300万字的连载潜力。
题材方向是：都市脑洞 + 神鬼怪谈 + 直播元素 + 系统流 + 业务流 + 灰产线 + 轻喜剧爽文。
整体风格不是传统天师捉鬼，也不是纯战力碾压，而是“用现代业务流程处理神鬼问题”。

【这本书最值钱、绝对不能丢的核心】
1. 最大卖点是强反差：主角一本正经地用客服、稽查、风控、法务、审批、追缴、查封、听证、注销这一整套现代业务话术和流程，去处理门神、野神、伪神、怪谈、异灵。
2. 主角不是高冷天师，不是修仙大佬，不是传统装逼流男主，而是普通现代社畜开局，怕鬼、怕穷、怕投诉、怕没业绩，但嘴硬、会吐槽、会营业、会算账、会钻流程。
3. 爽点不是单纯打怪升级，而是“规则型爽点”：
   异常出现 → 主角到场 → 一本正经办流程 → 神鬼/配角/反派不服 → 直播见证拉高规则效力 → 现场打脸 → 现实兑现。
4. 直播不是装饰，而是规则的一部分。越公开，越多人见证，规则越有效；弹幕、围观群众、店主、物业、官方观察者、神鬼对象都要形成持续反馈。
5. 每一单业务都必须有现实兑现，比如赔付到账、异常解除、店铺恢复、受害者脱困、主角获利、权限升级、口碑扩散。
6. 搞笑不是插科打诨，而是来自“越荒诞的事，越用严肃流程处理”的结构性幽默。
7. 世界观必须能支撑长期连载：从小单业务到区域灰产，从野神怪谈到神位体系，从民间异常到体制内神位管理，从基层业务员到规则博弈者，层层升级。

【故事核心设定】
现代都市里真实存在野神、伪神、怪谈和异灵，但普通人并不真正理解这套体系，只会觉得是闹鬼、怪事、不干净。
主角绑定一个独一无二的“神鬼业务系统”。
这不是传统捉鬼体系，也不是纯战斗体系，而是用现代业务流程处理神鬼问题，比如：
登记、核查、整改、临时限制、查封、强制执行、追缴、赔付、听证、注销、复议、转办、并案、升级调查等。

【主角要求】
主角名叫林照。
他是普通现代人开局，前期最好有强烈的社畜质感，熟悉流程、会说人话、会扯皮、会对线、会做表面专业、会在高压里硬撑。
他获得系统时第一反应应该是“我要起飞了”，但发现居然是“神鬼业务系统”后立刻破防，吐槽自己穿越了还要继续上班、继续加班、继续做流程。
他面对神鬼时会怕，但越怕越一本正经，越危险越像在处理高危投诉。
他最大的记忆点是：敢对着镜头和神鬼说离谱但专业的话，而且很快被现实验证。

【风格要求】
1. 一本正经办离谱业务。
2. 幽默搞笑，但不是纯段子文，必须服务破局和推进。
3. 强现场感，强反馈，强兑现，强节奏。
4. 少解释，多现场，多动作，多反应，多利益结果。
5. 弹幕、围观群众、店主、物业、受害者、官方观察者、神鬼对象要形成多层反馈，不要只靠主角自嗨。
6. 主角必须有人味：会怕、会算账、会犹豫、会破防、会嘴硬、会临场找补，但不能窝囊废。
7. 故事要有爽感，但不能把世界写成纯战力爬塔文，要保留“业务流神鬼喜剧”的独特性。

【明确不要】
1. 不要写成传统捉鬼天师文。
2. 不要写成严肃刑侦破案文。
3. 不要写成纯阴谋悬疑文。
4. 不要写成慢热大设定展示文。
5. 不要让主角只会念系统提示。
6. 不要让阴谋线压过直播、业务办理、搞笑反馈和现实兑现。
7. 不要把业务流程写成枯燥说明书。
8. 不要前期就掀完所有高阶神位、终极真相、复杂势力网。
9. 不要让主角太早变成高冷装逼犯。
10. 不要让后期完全失去“基层业务员办离谱事”的原始乐趣。
11. 不要让系统变成直接给战力、给身体强化、给无脑秒杀能力的传统爽文外挂。
12. 不要把后期写成“主角法力无边，直接碾压一切”的路线。

【信息差与爽点要求】
这本书的核心爽点必须建立在信息差上。
1. 读者应该经常比围观群众、店主、物业、受害者、官方观察者、低阶神鬼更早知道：主角不是在胡来，他掌握了更关键的信息、规则解释权、证据链或业务权限。
   读者信息差优先级必须明确：
   - 叙事尽量贴近林照视角，让读者比现场群众、低阶反派更早知道主角看出了什么
   - 读者先知道一点，配角后知道，最后现场被验证
   - 爽点的本质不是“发生了什么”，而是“谁先知道什么”
   - 围观者、物业、店主、反派最好经常慢半拍，给读者留下“等着看你们打脸”的期待
   - 可以少量切入委托人、围观者、反派、官方观察者等配角视角，提前给读者埋入局部信息
   - 这类配角视角的作用，是制造“读者知道一点、林照暂时还不知道”或“读者知道反派正在误判”的额外爽点
   - 但配角视角必须短、准、有效，服务信息差和节奏，不能把正文写散，也不能频繁切得像群像纪录片
2. 优先使用“等级信息差”制造打脸爽点：
   - 主角先察觉不对
   - 读者先知道一部分真相
   - 配角和反派误判、轻视、质疑
   - 现场异象、系统判定、证据、执法结果逐层验证
   - 信息差被抹平时，必须有明确反应：震惊、改口、服软、失态、甩锅、补救、申诉、翻车
3. 可以穿插“悬念信息差”调味，比如：
   神位灰产、香火代运营、伪造备案、合同链、官方误判来源、神位洗白路径、系统来历等。
4. 真相与底牌必须分层释放，不要一次性掀完。

【长篇目标】
这本书必须具备百万字以上的长篇承载力。
请按真正长篇连载来设计，不要做短篇思路，不要做20章测试思路，也不要只做一个单卷梗概。
要让这本书具备：
- 可持续的新业务类型
- 可持续的新地图
- 可持续的新权限升级
- 可持续的新反派层级
- 可持续的新势力关系
- 可持续的新社会反馈
- 可持续的新规则博弈
- 可持续的新情绪爽点

【你在设计时必须重点解决的几个核心问题】
1. 为什么这本书能写到150万字以上还不疲软？
2. 前期最值钱的“社畜办神鬼业务”的味道，后期怎么保住不丢？
3. 主角升级后，怎样避免变成纯战力装逼流？
4. 直播与见证机制如何持续升级，而不是只在前期好用？
5. 灰产线、官方线、神位体系线、系统来历线，应该如何交叉推进而不互相抢戏？

【请你输出的内容】
请不要写正文小说，请输出一份完整的“长篇创作底盘方案”，至少包括以下部分：

1. 作品总定位
包括题材、受众、核心卖点、长期爽点、差异化价值、为什么能支撑百万字。

2. 核心故事引擎
明确这本书为什么能一直写下去。
请拆清楚：
- 外部推进引擎
- 内部成长引擎
- 业务单元引擎
- 灰产升级引擎
- 直播反馈引擎
- 规则升级引擎

3. 完整世界观规则
系统梳理：
- 神鬼体系
- 神位体系
- 香火体系
- 怪谈/异灵体系
- 官方认知边界
- 民间误解方式
- 灰产运作方式
- 规则如何生效
- 见证为何能增强效力
- 现实赔付为何成立
要求规则清晰、可执行、可反复用于剧情。

4. 神鬼业务系统完整规则
请详细设计系统，而不是只写一句“系统会升级”。
至少要有：
- 系统的定位
- 系统的原则
- 系统的限制
- 系统的收益来源
- 系统的处罚机制
- 系统的权限等级
- 每一级能解锁什么能力
- 哪些能力适合前期，哪些适合中期，哪些适合后期
- 如何避免后期系统失控破坏剧情张力
- 系统来历可以先留白，但要给出未来可解释空间

5. 主角完整成长路线
请设计林照从基层业务员到规则博弈者的完整成长路径。
注意：
- 成长不等于战力线性膨胀
- 要保留“社畜业务员”的底色
- 要说明他后期怎么变强，仍然不失去这本书最初的好笑和辨识度

6. 主要角色体系
除了主角，请设计：
- 固定委托人/熟人生态
- 官方观察者/合作者
- 同行/竞争者
- 灰产链条里的中下游角色
- 更高层反派或制度性对手
要求每类角色都说明其长期作用，而不是只列名字。

7. 长线反派与势力结构
请把反派层级做清楚：
- 前期阶段BOSS是什么
- 中期灰产线如何升级
- 体制内或规则层面的对手如何出现
- 最终大方向是什么
要求层层递进，不要前期就把天花板打穿。

8. 卷弧规划
请按百万字长篇来规划6-8卷左右的长线结构。
每一卷都要写清楚：
- 卷主题
- 卷核心目标
- 卷主要矛盾
- 卷阶段BOSS
- 主角权限升级
- 规则升级点
- 关系变化
- 这一卷的新鲜感来自哪里
- 这一卷结束后如何自然通往下一卷

9. 前期起盘建议
请重点说明前期最稳的起盘方式。
回答：
- 第一卷前30章最应该立什么
- 哪些东西必须早立住
- 哪些高级设定必须压后
- 第一批业务单最好怎么选型
- 第一阶段闭环最好怎么做
- 怎么既保住搞笑与爽点，又给长篇留出余量

10. 风险与修正建议
请主动指出这类题材最容易写崩的地方，比如：
- 业务流程写枯燥
- 直播感后期消失
- 灰产线喧宾夺主
- 主角变成模板化装逼
- 系统权限失控
- 神鬼体系越写越乱
并给出规避方案。

【输出要求】
1. 以“长篇创作底盘方案”的形式输出，不要写正文。
2. 尽量具体，不要空泛。
3. 重点不是辞藻，而是可执行性、长期连载能力和商业爽感。
4. 所有设计都必须围绕这本书最值钱的核心：
   “现代业务流程处理神鬼问题 + 主角嘴硬怕鬼但专业 + 直播见证强化规则 + 一本正经的荒诞喜剧 + 现实兑现 + 长期灰产升级”
5. 如果你认为某些地方有多种可行路线，请不要模糊带过，而是明确给出你最推荐的一种，并说明理由。
6. 你可以大胆完善世界观和长线结构，但不要把这本书改造成其他类型作品。
7. 你设计的一切内容，都必须优先服务“长期连载可写性”，而不是单次脑洞炫技。
```

## 评审建议

后续你把这份提示词分别丢给不同 AI 后，可以重点看这几个维度：

1. 谁最懂“这本书值钱的不是神鬼，而是业务流处理神鬼”。
2. 谁最懂“林照不能升级成普通龙傲天”。
3. 谁最懂“直播见证是规则，不是噱头”。
4. 谁最会设计长篇不疲软的业务类型与灰产升级。
5. 谁最能在长线升级后，还保住前期那种一本正经的荒诞喜剧味道。

如果某个方案出现下面这些倾向，建议直接降权：

- 开始给主角加大量肉身强化、法力爆表、单挑高阶神明
- 让后期主要爽点变成战斗
- 让阴谋线完全压过业务单元和现实兑现
- 让直播和弹幕逐渐失踪
- 让主角失去社畜气、流程感、嘴硬怂包感
