## 一、这版做得非常好的地方（必须保留）
### 1. 核心定位钉得足够死
反复强调「用现代业务流程处理神鬼问题」是唯一核心，明确排除了传统捉鬼、刑侦、纯阴谋等跑偏方向，相当于给写作上了“安全锁”。只要严格执行，就不会丢掉这本书最独特的辨识度。

### 2. 主角人设边界清晰
把林照的「怂但专业、怕但硬撑、嘴硬爱算账」拆解得很具体，同时明确禁止“纯怂包”和“装逼犯”两个极端，人物底色不容易OOC。尤其是“越怕越一本正经、越慌越说业务黑话”的细节，是人物魅力的核心，抓得很准。

### 3. 单元爽点标准化
把「异常出现→质疑→走流程→见证加成→打脸→兑现→留钩」的闭环列了出来，写作时可以直接对标，保证每单都有完整爽点，不会出现“写着写着爽点没了”的情况。

### 4. 长线节奏有分层
四阶段推进+前期禁令，有效避免“前期掀完所有底牌”，保证了世界观的分层释放和长篇承载力。尤其是“前30章只做民间小场景”的要求，非常符合番茄男频的起盘逻辑——先用小而密的爽点抓住读者，再逐步放大格局。

### 5. 禁令具体可执行
十条禁止项都是这类题材最容易踩的坑，不是空泛要求，而是明确的“红线”。尤其是“不给肉身强化、不写法力秒杀、不让阴谋线压过业务线”，从根源上抑制了战力膨胀和主题跑偏。

## 二、需要补全/收紧的核心缺口（建议加上）
这版的主要问题是「部分规则只说了方向，没说刚性约束」，写作时很容易在细节上写飘，导致核心机制失效。建议补充以下7点，都是能直接影响爽点稳定性和长篇寿命的关键设计：

### 1. 补全「直播见证的刚性规则」，避免直播后期边缘化
目前只说了“公开见证加成”，但没明确「见证是增益还是必要条件」「负面共识会不会削弱效力」，这是直播会不会变成“装饰”的关键。
**建议补充明确：**
- 基础流程合规仅能触发微弱效力（仅神鬼层面感知，普通人看不到异象）；
- 公开见证是「效力显化、压制对方、现实兑现」的核心放大器，见证人数达到阈值，规则效果才会落到现实层面；
- 弹幕/现场的集体质疑（比如“程序不公”“没有证据”）会削弱规则效力，倒逼主角必须全程程序正义、证据链完整，不能胡来。

**作用：** 把直播从“加分项”变成“核心执法条件”，越到后期大案越需要全网公开见证，直播永远不会掉线。

### 2. 补全「系统处罚机制」，让流程有刚性
目前只说了权限边界，没说「违反流程、越权执法会怎么样」。没有惩罚的规则是没有约束力的，很容易写着写着主角就“想怎么来怎么来”，流程变成摆设，社畜感也会丢。
**建议补充明确：**
- 程序瑕疵（跳过步骤、证据不足）直接导致执行失效，业务白做；
- 越权执法扣除对应业务点，累计3次降信用评级，限制高级权限接单；
- 被申诉成功（确有程序违规）扣服务分，影响后续工单质量和佣金比例；
- 主角的核心焦虑之一，就是“怕程序错了扣绩效、丢评级、赚不到钱”，和现实社畜怕扣工资完全对齐。

**作用：** 强化“程序正义”的核心地位，也让主角“小心翼翼走流程”的行为更合理，社畜底色更稳。

### 3. 补全「业务点稀缺性与兑换规则」，抑制战力膨胀
这是防止后期系统失控的核心阀门，也是主角“怕穷、爱算账”的动机基础，目前完全没提，很容易后期业务点泛滥，主角随便用高阶权限。
**建议补充明确：**
- 兑换比例固定：**1业务点 = 10000元现金（单向兑换，现金不能换业务点）**；
- 前期基础单奖励0.5-2个业务点，高阶操作（查封、听证、批量执行）单次消耗十几到上百业务点；
- 主角永远处于“业务点不够用”的状态，每次执法都要算成本，能走简易流程绝不走复杂流程。

**作用：** 从经济层面锁死主角的能力上限，永远不会“无敌”，也让“算账、抠门、算性价比”的人设更立得住。

### 4. 补全「术语统一规范」，避免世界观混乱
之前底盘明确了「异常风险用“阶”，业务职级用“级”，严禁混用」，这版没强调，写作时很容易写乱，世界观严谨性会打折扣。
**建议补充明确：**
- 描述异灵、野神、伪神的强度，统一用「X阶」（如3阶野神、2阶怪谈）；
- 描述主角的系统权限，统一用「X级」（如1级见习业务员、3级高级业务员）；
- 全程严禁混用，不出现“2级异灵”“3阶业务员”这类错误表述。

**作用：** 保持世界观术语的一致性，专业感更强，也不容易出现前后设定矛盾。

### 5. 补全「喜剧的来源约束」，避免硬插段子
目前只说了“轻喜剧”，但没限定笑点来源，很容易写成硬加网络梗、为了搞笑而搞笑，反而破坏剧情和人设。
**建议补充明确：**
- 所有笑点必须是**结构性反差**：严肃专业的业务流程 vs 荒诞离谱的神鬼事件；主角表面稳如老狗 vs 内心慌得一批；反派嚣张跋扈 vs 被流程按在地上摩擦。
- 禁止硬加脱离剧情的网络梗、低俗段子，幽默必须服务人设和剧情，不能为了笑而笑。

**作用：** 保证喜剧感是这本书的“自带属性”，而不是外挂段子，高级感和持久度都会更强。

### 6. 补全「读者信息差原则」，强化爽点代入
目前提到了信息差打脸，但没明确「读者视角的优先级」，这是番茄爽文的核心技巧——读者开上帝视角，才会有“等着看你们傻眼”的追更欲。
**建议补充明确：**
- 叙事优先贴近主角视角，读者同步知道主角的判断、系统的提示、证据的情况；
- 围观群众、反派、官方的认知永远慢半拍，他们的质疑、轻视、误判，读者提前就知道是错的；
- 真相永远分层释放：读者先知道→现场异象验证→配角反应过来，三步走完，爽感拉满。

**作用：** 把信息差爽点标准化，每单都能复用，读者代入感和追更意愿会强很多。

### 7. 补全「灰产线索露出节奏」，保证长线连贯
目前说了灰产是长线主轴，但没说前期怎么漏线索，很容易要么漏太多提前掀底，要么完全没线索后期接不上。
**建议补充明确：**
- 前期每3-5个业务单元，漏1个灰产碎片线索（比如假证一角、代运营的聊天记录、统一的话术模板、同款违规神印）；
- 线索只露碎片，不解释、不展开，读者知道“背后有人”，但不知道全貌；
- 每卷末尾把本卷的碎片线索串起来，引出下一层级的反派，自然过渡到下一阶段。

**作用：** 长线暗线持续勾着读者，但又不抢单元业务的主戏，节奏松紧合适。

## 三、落地执行的补充建议（写作时直接用）
### 1. 所有规则都用“结果展示”，不用旁白解释
不要大段科普“香火是什么”“规则为什么生效”，全部用现场结果带出来：
- 不说“香火是信念能量”，写主角追缴违规香火后，店主脸色立刻红润，店里当天客流翻三倍，收银台不停响；
- 不说“见证增强效力”，写主角单独念整改通知书毫无反应，一开直播人数破千，对方当场被压得半跪，门窗无风自动。

### 2. 业务话术要“抄现实”，越真实反差越强
整改通知、查封告知、听证流程，直接对标现实中市场监管、综合执法的官方话术，稍微改几个词就能用，越像真的政务文书，对着神鬼念的时候反差感就越强，喜剧效果和专业感同时拉满。

### 3. 每单必须有「三层反馈」，杜绝主角自嗨
至少三层反应同时写，爽感才立体：
- **当事人层**：从绝望、怀疑到惊喜、信服；
- **围观层**：从吐槽、看戏到震惊、刷屏、口口相传；
- **反派层**：从嚣张、不屑到懵逼、破防、服软、申诉。

### 4. 章末钩子常态化，不只单元尾才有
番茄的追更核心在章末钩子，每一章最后都要留一个小期待/小悬念，比如：
- “林照话音刚落，墙角的阴影里，缓缓伸出了一只青紫色的手。”
- “系统突然弹出一行提示：检测到该神位备案编号异常，涉嫌伪造。”
- “老板刚要道谢，手机突然弹出一条转账提醒，备注栏写着：违规香火赔付。”

小钩子拉着读者一章章追，大钩子拉着读者一卷卷追，节奏就稳了。
