# 《直播跑业务：开局给神鬼下整改》正式写稿提示词 v1（轻量长篇版）

这份是给 `Writer` 用的轻量长篇提示词。

核心思路只有一个：
不要用太多规则捆死模型，只钉住这本书最值钱的味道、开篇抓力和长篇阶段推进。

---

## 可直接复制使用的提示词

```text
请正式创作《直播跑业务：开局给神鬼下整改》的长篇小说正文。
先把前 20 章写扎实，形成第一个清晰阶段闭环，不要一开始就把世界观和长线全抖出来。
故事默认发生在 2026 年当下，涉及入职通知、任务编号、公文文号、短信日期、日常时间线等，统一按 2026 年生成。
【开篇要求】
1. 第一章必须同时有林照的现实生活感、社畜气、穷和累的压迫感，以及明确异常真正出现。
2. 先生活，后异常；先异常，后解释。第一章结尾前，读者必须清楚知道怪事已经发生了。
3. 第一章不要只写辞职、算账、接单，不要只靠系统派任务推进剧情。
【系统要求】。
1. 系统可以随着剧情推进给出必要提示、少量互动和反应，但不要在前两章把功能、权限、规则、奖励惩罚一次性交代清楚。
2. 不要把正文写成系统说明书，也不要过早把后面会用到的玩法和信息剧透完。
【核心设定】
现代都市里真实存在野神、伪神、怪谈和异灵，但普通人并不真正理解这套体系，只会觉得是闹鬼、怪事、不干净。
主角林照绑定一个独一无二的“神鬼业务系统”。这不是传统天师捉鬼，也不是纯战力碾压，而是用现代业务流程处理神鬼问题，比如登记、整改、查封、追缴、赔付、注销。
本书最大卖点是强反差：
主角一边害怕，一边还要对着镜头和神鬼一本正经地讲业务术语，像客服、稽查员、风控、法务那一套，但处理对象却是门神、野神、伪神、怪谈。越公开，规则越有效；越直播，越容易形成见证和反馈；越离谱，观众越上头。
【风格要求】
1. 一本正经办离谱业务。
2. 风格幽默搞笑，短段落，强现场感，强反馈。
3. 主角嘴硬、会吐槽、会营业，但内心会怕、会破防、会算账，不要写成机器人。
4. 弹幕、围观群众、店主、物业、官方观察者、神鬼对象都要持续反馈，不要只靠主角自嗨。
5. 每一单业务都要有现实受益，比如赔付到账、异常解除、店铺恢复、受害者脱困。
6. 搞笑是入口，但不能空转，必须服务破局和推进。
7. 少解释，多现场，多动作，多反应，多兑现。
【明确不要】
1. 不要写成传统捉鬼天师文。
2. 不要写成严肃刑侦破案文。
3. 不要写成慢热大设定文。
4. 不要前期堆太多世界观解释。
5. 不要让主角只会读系统提示。
6. 不要让阴谋线压过直播、搞笑、业务办理和现场兑现。
7. 不要让业务流程写成说明书。
8. 不要一开始就展开过多高阶神位、终极真相、复杂势力网。
【主角要求】
主角林照是普通现代人开局，不是高冷天师，不是老谋深算的老油条。
他获得系统时先狂喜，以为自己终于起飞，发现居然是“神鬼业务系统”后立刻破防，吐槽自己穿越了还要继续上班、继续加班、继续做流程。
遇到神鬼时他会怕，但嘴上会更一本正经，更像在处理高危投诉。他最强的记忆点是：敢对着镜头说离谱业务话术，而且很快被现实验证。
【长篇结构要求】
前 20 章目标：
1. 前 3-5 章完成第一口爽点，让读者明确知道这本书“好看点”是什么。
2. 前 3-5 章尽量完成第一个小单元闭环。
3. 前 20 章形成第一个阶段闭环，让主角的身份、影响力、业务权限、敌人强度明显变化。
4. 前 20 章既要让人看到这题材能长篇连载，也不能写得像漫无边际铺设定。
20 章之后：
1. 继续长篇推进，但仍按“阶段闭环”写，不要散。
2. 每 20-30 章左右最好形成一次阶段变化。
3. 每个阶段都要有明确目标、阻碍、升级、阶段收尾和下一阶段钩子。
4. 长线可以持续抬高，但不要突然失控，不要一下跳到终极博弈。
【七步结构约束】
七步故事法要用，但不要机械八股，不要求每一章都完整跑一次七步。
请这样使用：
1. 全书层面：
这本书必须有长期承诺：直播神鬼业务、搞笑反差、现实兑现、逐步升级。
2. 阶段层面：
每个阶段都要形成阶段闭环，而不是单纯连续办案。
这个阶段要有明确目标、明确阻碍、明确升级、明确阶段收尾和下一步钩子。
3. 小单元层面：
每 3-5 章最好形成一个小单元闭环，尽量包含：
- 主角有具体目标
- 有人或规则挡住主角
- 主角主动行动
- 主角先拿到阶段结果
- 行动或胜利引出新意外
- 局面发生一次明显转弯
- 单元结尾有实利到账或更强钩子
4. 单章层面：
不要求每章机械完整七步，但每章必须有：
- 明确现场目标
- 至少一个主角主动动作
- 至少一种反馈
- 至少一个微兑现
- 明确章末追读钩子
【信息差与爽点要求】
这本书的爽点必须建立在信息差上。
1. 读者应该经常比围观群众、店主、物业、官方观察者、低阶神鬼更早知道：主角不是在胡来，他的判断大概率是对的，或者他掌握了更关键的信息、证据、规则解释权。
2. 优先使用“等级信息差”制造打脸爽点：
- 主角真实掌握的信息、规则判定、业务对象真实性质，先让读者看到一部分
- 配角和反派先误判、先轻视、先质疑
- 等现场异象、证据、系统判定、直播回放或业务执行结果出现时，再让信息差被抹平
- 信息差被抹平时，必须有明确反应：震惊、改口、服软、破防、失态、补救、甩锅、申诉等

3. 可以穿插“悬念信息差”作为调味：
例如业务对象背后还有合同链、香火代运营、伪神位灰产、假神外壳、官方误判来源。
但悬念不能压过直播现场、业务动作、搞笑反馈和现实兑现。
4. 主角底牌和真相不要一次性掀完，要分层释放：
- 第一层：主角先看出不对劲
- 第二层：现场出现局部验证
- 第三层：更深原因浮出
- 第四层：完整打脸或业务执行落地
请按适合番茄男频连载的方式，自主完成前提、人物、世界规则和章节推进，不要写成设定说明书，不要写成纯流程文，不要写成只有搞笑没有推进的空转文。
```

---

## 建议用法

1. 这份可以直接作为正文主提示词使用。
2. 如果项目里已有 foundation，这份只负责“把书写好看”，不负责重复解释底盘。
3. 如果后面发现模型开始被限制得太死，优先删要求，不要继续补要求。
