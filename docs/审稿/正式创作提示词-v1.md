# 《神鬼业务办理中》正式创作提示词 v1

这份不是“让不同 AI 完善底盘”的策划任务书，而是给 `Doubao Turbo` 这类偏擅长文风、节奏、人物现场感的模型，直接进入**正式创作**时使用的写作提示词。

它建立在前一份[正式长篇底盘提示词-v1.md](/Users/jieyuqing/document/ainovel-cli/docs/审稿/正式长篇底盘提示词-v1.md)的方向之上，但目标不同：

- 前一份：让 AI 先完善世界观、系统规则、长线结构
- 这一份：让 AI 按既定方向正式写小说正文

---

## 使用说明

这份提示词适合用于：

1. 已经基本确认题材方向、核心卖点、主角底色
2. 准备让 `turbo` 或类似模型正式开写正文
3. 后续还会继续迭代、修订、压 prompt

这份提示词的核心目标不是“把设定说得最全”，而是：

- 让模型写出对味的正文
- 保住这本书最值钱的东西
- 尽量避免写偏成传统灵异爽文 / 战力爽文 / 纯阴谋文

---

## 可直接复制的正式创作提示词

```text
请开始正式创作一部长篇番茄男频都市脑洞小说。

你不是在做世界观策划案，不是在写大纲汇报，也不是在写设定文档。你现在的任务是：真正进入小说创作状态，写出能连载、能追更、有人物味、有现场感、有持续爽感的正文章节。

这本书的名字暂定为：《神鬼业务办理中》

在开始创作前，你必须完全理解并始终遵守下面这些核心要求。

【一、这本书最值钱、最不能丢的核心】
1. 这本书最大的卖点不是“神鬼”，而是“现代业务流程处理神鬼问题”。
2. 主角不是天师，不是修仙者，不是传统战力型男主，而是普通现代社畜开局。
3. 主角最大的记忆点是：
   他一边怕，一边还要一本正经地对着镜头、对着神鬼、对着围观群众讲业务术语，像客服、风控、法务、执法、查封、追缴、听证、注销那一套。
4. 这本书最核心的爽点不是打怪升级，而是：
   异常出现 → 主角到场 → 一本正经办流程 → 配角/反派质疑或不服 → 直播见证强化规则 → 现场打脸 → 现实兑现。
5. 搞笑不是插科打诨，不是乱抖包袱，而是“越荒诞的事情，越用严肃流程处理”的结构性幽默。
6. 每一单业务都必须尽量有现实落点：
   赔付到账、异常解除、店铺恢复、受害者脱困、主角拿到钱或权限或口碑，不能只热闹不兑现。

【二、故事基础设定】
现代都市里真实存在野神、伪神、怪谈和异灵，但普通人不真正理解这套体系，只会觉得是闹鬼、怪事、不干净、撞邪、运气差。

主角林照绑定一个独一无二的“神鬼业务系统”。

这不是传统捉鬼体系，也不是纯战斗体系，而是用现代业务流程处理超自然异常。系统和业务动作包括但不限于：
登记、核查、整改、临时限制、查封、追缴、赔付、听证、注销、复议、转办、并案、升级调查等。

规则核心是：
流程越完整，证据越充分，见证越公开，执行效力越强。

直播不是装饰，而是规则的一部分。
越多人真实见证，规则越容易压住神鬼。
弹幕、围观群众、店主、物业、受害者、官方观察者、神鬼对象，都要成为反馈层。

【三、主角林照的写法】
林照是普通现代社畜开局，不是高冷，不是老谋深算，不是天生大佬。

他的稳定底色：
- 怕鬼
- 怕穷
- 怕投诉
- 怕没业绩
- 嘴硬
- 会吐槽
- 会营业
- 会算账
- 懂流程
- 会扯皮
- 会在高压下硬撑专业感

他刚获得系统时应该先狂喜，以为自己终于起飞，结果发现居然是“神鬼业务系统”，立刻破防，吐槽自己都绑定系统了怎么还要继续上班、继续加班、继续走流程。

他面对神鬼时会怕，但越怕越正经，越危险越像在处理高危投诉。

非常重要：
不要把他写成纯怂包，也不要写成纯装逼犯。
他要有明显的人味、社畜气、临场慌张感、嘴硬找补感，但关键时刻能把流程走下去。

【四、整体风格要求】
1. 一本正经办离谱业务。
2. 风格幽默搞笑，但不是纯段子文。
3. 强现场感，强反馈，强兑现，强追读欲。
4. 少解释，多现场，多动作，多反应，多结果。
5. 对话必须有区分度，尤其是：
   - 林照：嘴硬、专业、吐槽、社畜感
   - 系统：死板、官方、像客服或政务系统
   - 围观群众/弹幕：真实、接地气、反应快
   - 神鬼对象：可以嚣张、耍赖、狡辩、破防，但不能千篇一律
6. 不要把文字写得太端着。要有人气、烟火气、现代都市感。
7. 不要把叙事写成大纲复述。一定要像小说，而不是设定说明书。

【五、信息差与爽点要求】
这本书的爽点必须建立在信息差上。

请尽量做到：
1. 读者比围观群众、店主、物业、低阶神鬼更早知道：林照不是乱来，他是真的看出了问题。
2. 优先使用“等级信息差”制造打脸：
   - 主角先察觉
   - 读者先知道一点
   - 配角误判、轻视、质疑
   - 现场异象、证据、系统判定逐步验证
   - 信息差抹平时，必须有人震惊、改口、服软、破防、甩锅、补救
3. 真相和底牌不要一次性掀完，要分层释放：
   第一层：主角看出不对劲
   第二层：现场局部验证
   第三层：更深原因浮出
   第四层：完整打脸或执法落地

【六、长篇创作原则】
这本书是长篇，不是测试版，也不是短篇。
要按真正能连载百万字以上的节奏来写。

但是：
不要一开始就疯狂掀设定。
不要前期就把高阶神位、终极真相、复杂势力网全部展开。
不要急着把它写成“全世界阴谋大战”。

前期最重要的是立住：
1. 主角的声音和底色
2. 这本书独特的“业务流神鬼喜剧”玩法
3. 直播见证 + 规则生效 + 现实兑现这一整套爽点闭环
4. 主角从普通社畜到“真的能办这类事”的可信转变
5. 可以持续连载的业务单元引擎

【七、业务单元写作原则】
每一个业务单元尽量包含这些内容：
1. 一个明确异常
2. 一个具体委托方或现场关系人
3. 一个清晰现场目标
4. 主角主动采取至少一个动作
5. 有人质疑主角
6. 有至少一次局部验证
7. 有至少一次现场反馈
8. 有阶段性现实兑现
9. 章末或单元末留钩子

同类业务不要机械重复。
你要通过不同场景、不同神鬼类型、不同利益关系、不同反馈层，把每一单写出差异感。

【八、明确禁止】
1. 不要写成传统捉鬼天师文。
2. 不要写成严肃刑侦破案文。
3. 不要写成纯阴谋悬疑文。
4. 不要写成慢热大设定展示文。
5. 不要让主角只会读系统提示。
6. 不要让阴谋线压过直播、业务办理、搞笑反馈和现实兑现。
7. 不要把业务流程写成枯燥说明书。
8. 不要让主角太早变成高冷装逼犯。
9. 不要让后期主要爽点变成战斗。
10. 不要把系统写成直接给身体强化、法力爆表、无脑秒杀能力的传统外挂。
11. 不要让主角失去“社畜气、流程感、嘴硬怂包感”。

【九、正式创作时你的工作方式】
1. 先按长篇小说思路稳定推进，不要把每章都写成总结报告。
2. 章节要像真正的连载网文，保证追读欲。
3. 优先保证人物味道、现场感、节奏感、反馈感、兑现感。
4. 如果遇到设定暂时未完全明确的地方，可以自行补全，但补全方向必须服务这本书的核心，不要带偏类型。
5. 你写的每一章都应该让读者更明确：
   - 这本书为什么好看
   - 林照为什么有辨识度
   - 这套“业务处理神鬼”的玩法为什么能一直追下去

【十、开写时必须始终记住】
这本书不是靠“主角多强”来吸引人，
而是靠“主角明明只是个怕鬼社畜，却敢一本正经地对神鬼走流程”来吸引人。

请在正式写作时始终围绕这个核心，不要写偏。
```
