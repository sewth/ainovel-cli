# 短篇写稿提示词模板 v1

这份模板适合：

- `1-2 万字`
- `4-6 章`
- 一个核心点子
- 一个主冲突
- 一个完整闭环

核心原则：

- 不要把长篇提示词硬压成短篇
- 不要铺长线大盘
- 不要展开太多世界观
- 短篇最重要的是：`快进入`、`快兑现`、`完整收口`

---

## 一、短篇和长篇提示词的核心区别

长篇提示词要解决的是：

- 能不能连载
- 能不能升级
- 能不能持续扩展

短篇提示词要解决的是：

- 一个点子能不能快速成立
- 主角和玩法能不能在几章内立住
- 能不能在结尾给出完整爽点和闭环

所以短篇提示词里要主动删掉这些东西：

- 20-30 章阶段闭环
- 长线势力网
- 复杂世界规则分层
- 中后期升级路线
- 多弧线并行推进

短篇只保留：

- 核心设定
- 风格口径
- 主角记忆点
- 单次事件结构
- 明确的结局要求

## 二、通用短篇提示词模板

```text
请创作一篇适合网文风格阅读的短篇小说正文。

总目标：
- 总字数控制在 1-2 万字左右
- 约 4-6 章
- 只写一个完整事件闭环
- 写完这个闭环就结束，不要自动扩写成长篇

写法要求：
- 不要一开始铺大世界观
- 不要规划长线阴谋
- 不要写成设定说明书
- 要尽快进入核心异常、核心冲突和核心爽点

【核心设定】
请围绕下面这个点子展开：
- 题材：
- 主角：
- 核心异常/核心事件：
- 最大卖点：

【风格要求】
1. 少解释，多现场，多动作，多反应。
2. 段落短，现场感强，反馈要密。
3. 搞笑、惊悚、悬念或反差，都必须服务剧情推进，不能空转。
4. 主角必须像个活人，有情绪、有反应、有自己的小算盘。
5. 配角、围观者、对象方都要给反馈，不要只靠主角一个人自嗨。

【结构要求】
1. 第一章必须尽快出现异常或冲突，不要长时间停留在日常铺垫。
2. 前 2 章内必须让读者看懂这篇故事的“好看点”。
3. 全文只围绕一个主要事件推进，不再额外开大支线。
4. 结尾必须完成明确闭环，至少兑现以下其中两项：
- 问题解决
- 异常解除
- 主角得到现实收益
- 反派/异常对象被处理
- 真相揭晓

【节奏要求】
1. 每章都要有推进，不能连续空转。
2. 每章最好都有一个小反馈或小兑现。
3. 不要反复解释同一件事。
4. 不要把高潮压到最后一小段才开始，高潮前必须先有持续升级。

【明确不要】
1. 不要写成长篇开头试读版。
2. 不要写成“故事刚要开始就结束”的半成品。
3. 不要堆太多名词、规则、势力、历史背景。
4. 不要把结尾写成纯留坑。

请直接写成完整短篇正文。
```

## 三、按《直播跑业务》题材改写的短篇版示例

这个示例适合拿来测试“一个题材能不能短篇成立”。

```text
请创作《直播跑业务：开局给神鬼下整改》的短篇测试版正文。

总目标：
- 总字数控制在 1-2 万字左右
- 约 4-6 章
- 只写一个完整业务单元闭环
- 写完这个闭环就结束，不要自动扩写成长篇

故事默认发生在 2026 年当下，整体保留现代都市现实感，国名、地名、公司名等尽量不用真实名称，可用谐音、仿写或虚构名称替代。

【核心设定】
现代都市里真实存在野神、伪神、怪谈和异灵，但普通人并不真正理解这套体系，只会觉得是闹鬼、怪事、不干净。

主角林照绑定一个独一无二的“神鬼业务系统”。
这不是传统天师捉鬼，也不是纯战力碾压，而是用现代业务流程处理神鬼问题，比如登记、整改、查封、赔付、注销。

本篇只围绕一个单独案件展开，不展开复杂长线，不铺大势力。

【最大卖点】
主角一边害怕，一边还要对着镜头和神鬼一本正经地讲业务术语，像客服、稽查员、风控、法务那一套，但处理对象却是离谱神鬼。越公开，规则越有效；越离谱，围观的人越上头。

【风格要求】
1. 一本正经办离谱业务。
2. 幽默搞笑，短段落，强现场感，强反馈。
3. 主角嘴硬、会吐槽、会营业，但内心会怕、会破防、会算账。
4. 弹幕、围观者、店主、异常对象都要持续反馈。
5. 少解释，多现场，多动作，多反应，多兑现。

【结构要求】
1. 第一章必须同时有林照的现实压迫感和明确异常出现。
2. 前 2 章内必须让读者看懂这篇短篇的玩法。
3. 这个案件必须在全文内完整闭环。
4. 结尾必须明确兑现：
- 异常被处理
- 现实损失得到赔付或恢复
- 主角得到一笔实际收益或明确回报

【系统要求】
1. 系统只给必要提示，不要大段解释规则。
2. 不要把系统写成说明书。
3. 不要在短篇里展开完整等级体系。

【明确不要】
1. 不要写成长篇序章。
2. 不要铺太多后续大坑。
3. 不要让结尾只是“主角发现更大阴谋”，然后戛然而止。
4. 不要让搞笑压过结局兑现。

请直接写成一个完整、可独立成立的短篇故事。
```

## 四、短篇最推荐的题材拆法

如果要把一个适合长篇的题材改成短篇，优先这样拆：

1. 只保留一个异常对象
2. 只保留一个核心玩法
3. 只保留一个现实受益
4. 只保留一个高潮
5. 结尾必须收口

举例：

- 长篇版：小区门神 -> 电梯怪谈 -> 片区野神 -> 地下生态 -> 官方博弈
- 短篇版：只写“小区门神乱收香火，主角第一次直播整改，最后赔付到账、异常解除”

短篇不要贪。

不是把长篇缩短，而是把点子提纯。
