# 世情短篇写稿提示词 v2：七步推进版

使用时填完方括号内容，再把代码块整体复制给模型。

```text
请直接创作一篇完整的世情短篇小说正文。

全文使用第一人称。篇幅约 1-2 万字（硬限制，不允许突破，写大纲要考虑字数，短篇要凝练剧情不能拖），只写一个核心事件，写完闭环即结束。不要写成长篇序章，不要额外铺大阴谋或新支线。

【本篇信息】
题材场景：[家庭 / 婚姻 / 职场 / 邻里 / 人情债 / 污名洗清 / 其他]
推进路线：[高密度反制 / 预判设局 / 规则回收 / 查证反转，四选一]
主角目标：[身份、处境、最想保住或拿回的具体东西]
核心压迫：[谁通过什么关系、规则或说法，正在夺走主角什么]
主角暂时不能翻脸的原因：[亲情、职位、证据、名声、现实成本等]
对手真正想拿到的利益：[钱、房子、名额、职位、署名、客户、资格、解释权等]
前半主动反制：[主角具体做什么，迫使谁回应或改变局面]
阶段小胜：[高潮前主角拿回什么筹码；对手或旁观者发生什么变化]
结局结果：[主角拿回什么；对手失去什么；关系或规则如何改变]

【全篇必须按七步推进】
1. 触发：开头立刻发生夺利、羞辱、异常或关系变故。
2. 压迫：让读者看清主角失去什么，以及为什么此刻不能硬撕。
3. 主动反制：前半主角必须做一次会改变局面的行动，不能只是忍、查资料、存证或回忆。
4. 阶段结果：高潮前必须有一次可见小胜，例如收回一项特权、逼对手留下把柄、获得公开支持、拿回部分利益或让对手首次掉人设。
5. 反扑升级：对手发现威胁后，用更狠、更现实的方式压回来；新压力必须来自其贪心、规则或关系网。
6. 高潮转向：主角用前面拿到的筹码，在公开场、关键关系或规则程序中正面翻盘。
7. 结果兑现：回应开头的憋屈，主角拿回实际结果，对手承担相称后果。

存证、调查、查资料、回忆只能算准备，不能单独算“主动反制”或“阶段结果”；它们必须立刻转化为让对手、旁观者或利益关系发生变化的行动。

【写法】
1. 少解释，多现场、对白、动作和结果；不要反复受气、查证或吵同一件事。
2. 主角可以克制，但不能窝囊。每次受压后都要调整策略、收回一点边界或推进一步。
3. 对手不能只负责坏，必须有具体利益和自以为压得住主角的理由。
4. 旁观者可以先误解、沉默或跟风，随后要因事实和利益变化而动摇、转向或作证。
5. 严守人物视角，任何角色都不能知道自己没有得到的信息。
6. 高潮由主角的关键行动推动，不要靠天降证据或别人替主角主持公道。
7. 直接开始正文，不要先列大纲、解释设定或询问问题。
```
