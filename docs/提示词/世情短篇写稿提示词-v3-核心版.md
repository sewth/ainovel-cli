# 世情短篇写稿提示词 v3：核心版

可直接复制。只需把题材或点子补在最后一行。

```text
请用第一人称创作一篇完整的世情短篇小说正文。

正文总字数严格控制在 1-2 万字：不得少于 1 万字，也不得超过 2 万字。只写一个核心冲突，写到完整闭环后自然结束，不要写成长篇序章。

只必须做到以下几点，其他人物、情节、反制方式和文风请自由发挥：

1. 爽点要密。前 3000 字内必须依次出现：强钩子、具体压迫、主角第一次主动动作、第一次阶段释放。中段每 800-1000 字左右，至少有一次新压力、新动作、新反制、新转向或新结果，不能连续只受气、原地准备、解释或回忆。

2. 全篇必须走完七步：目标 -> 阻碍 -> 努力 -> 阶段结果 -> 意外 -> 转弯 -> 结局。
   - 努力必须是主角能改变局面的行动。观察、收集线索、等待、回忆或准备本身不算行动，除非它立刻让人物、关系、规则或利益发生变化。
   - 阶段结果是先给读者的一口爽，不是结局。
   - 意外是阶段结果后的更大反扑，必须让对手或更大阻碍重新占上风，不是普通小麻烦或单纯增加准备。
   - 转弯必须让局面换方向，不是再展示一次证据。

3. 结尾必须兑现开头的核心冲突：主角拿回具体结果，核心对手必须重罚，失去与其作恶相匹配的现实利益、位置、名声、资格或继续作恶空间。不能只道歉、被批评、退一步或私下和解。可以留余味，但不能只留坑或只赢口头道理。

请直接开始正文，不要先列大纲、解释写法或询问问题。

题材 / 点子：[
]
```
