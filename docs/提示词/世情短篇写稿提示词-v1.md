# 世情短篇写稿提示词 v1

使用时只需填完方括号内容，再把代码块整体复制给模型。

```text
请直接创作一篇完整的世情短篇小说正文。

篇幅约 1-2 万字，4-6 章。全文只写一个核心事件，写完闭环即结束，不要把它写成长篇序章，不要额外铺大阴谋或新支线。

【本篇信息】
题材场景：[家庭 / 婚姻 / 职场 / 邻里 / 人情债 / 污名洗清 / 其他]
主角：[身份、当前处境、最想保住或拿回的具体东西]
核心压迫：[谁通过什么关系、规则或说法，正在夺走主角什么]
主角不能立刻翻脸的原因：[亲情、职位、证据、名声、现实成本等]
对手真正想拿到的利益：[钱、房子、名额、职位、署名、客户、资格、解释权等]
主角的关键抓手：[能力、证据、旧账、规则、资源、人脉或一次选择]
结尾结果：[主角拿回什么；对手失去什么；关系或规则如何改变]

【写法】
1. 开头尽快让压迫或冲突当场发生，不要先长篇交代背景。
2. 让读者清楚看到主角失去什么、对手多拿了什么、主角为什么暂时不能硬撕。
3. 主角可以忍，但不能全程被动；前半必须有一次主动行动或反制。
4. 中段要有局部小赢，再有更强反扑或新压力；不要反复受气、解释、查证或吵同一件事。
5. 对手不能只负责坏，必须有具体利益和自以为能压住主角的理由。
6. 旁观者可以先误解、沉默或跟风，后面要因事实和利益变化而动摇、转向或作证。
7. 少解释，多现场、对白、动作和结果。细节只写能推进压力、选择或反击的部分。
8. 严守人物视角，任何角色都不能知道自己没有得到的信息。
9. 高潮由主角的关键行动推动，不要靠天降证据或别人替主角主持公道。
10. 结尾必须兑现开头的憋屈：主角拿回实际结果，对手承担与伤害相称的后果。可以留余味，但不能只留坑。

请直接开始正文，不要先解释设定、列大纲或询问问题。
```
